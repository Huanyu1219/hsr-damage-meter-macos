# M9 历史管理、稳定性与使用细节

用户选择跳过 M8 跨场分析及浮窗外观设置，只推进历史管理、稳定性检查和使用细节。

## 历史管理

历史窗口“管理”菜单支持多选删除、清空及永久/7/30/90/365天保留；行右键可删除单场。删除与启用保留期限均二次确认。永久保留为默认。启动及每小时执行已确认的期限清理，设置期限立即清理一次。事务删除与外键级联清理原始事件，进行中的 running 记录不删除。清理范围按场次开始时间，保留期限不是按游戏轮次。

删除不会清空当前面板。已删除的结算记录解除内存检查点关联，避免下一次重置把它重新写回。批量选择使用系统 List 的多选交互，Cmd 点击选取。

## 稳定性

旧 WebSocket 的 receive 返回后再检查连接代次和取消状态，防止旧连接事件跨越重连边界。模拟服务支持独立本机端口，避免占用游戏1305。生产默认仍为1305且地址固定loopback。

NSPanel监听屏幕配置变化，显示器拔出或分辨率改变时重新约束到可见屏幕并保存位置。原有点击穿透恢复路径保留。

验证：38项Swift测试通过、1项Nanoka在线测试本轮跳过；含20场共20000条Decimal事件持续回归、断线完整性、删除后不复活、保留期限边界、原始事件级联删除及当前场次保护。另重复网络联调覆盖接收器停止/重连后新场次不累加旧伤害，握手和心跳通过。格式、发布构建及签名检查通过。

该压力回归是加速事件测试，不等同数小时实机游戏测试；YAAGL游戏重启、全屏/Spaces及多屏物理插拔实际体验仍需用户验收。没有使用Computer Use，也没有修改DLL。

## 使用细节

App激活时可使用快捷键：Cmd+1 主面板、Cmd+2 历史、Cmd+Shift+O 显示/隐藏浮窗、Cmd+Option+O 恢复浮窗操作。不是全局热键，不截获游戏输入。菜单项直接显示快捷键。

资料更新结果移至工具栏下方，避免较长提示挤压按钮，并提供辅助功能标签。保留现有亮暗配色、减少动画与减少透明度支持，不增加无关指标。
