# M5 原生浮窗

使用 NSPanel + SwiftUI，复用 AppModel 的 10 Hz 统计快照，无新增 Collector 连接、轮询或 DLL 修改。

- 极简 240×190：角色和全队占比。
- 紧凑 320×340（默认）：角色头像、属性色、伤害条、绝对伤害、全队总伤害与 DPA。
- 详细 380×360：增加角色 DPS。按用户已确认的要求不显示最高单次或次数。
- 暗色背景；遵守减少透明度，柱形沿用减少动态效果设置。
- 主面板和菜单栏均可显示/隐藏浮窗。鼠标悬停显示模式菜单与隐藏按钮；背景可拖动。
- 非激活窗口，不获取键盘焦点，失去前台状态时仍显示；窗口等级为 floating。
- 菜单栏始终提供鼠标穿透开关及“恢复浮窗操作”，恢复会关闭穿透、显示窗口并移回有效屏幕区域。
- 模式、位置、可见性、穿透及跨桌面设置保存到 UserDefaults。尺寸随模式保存和恢复，暂不提供自由缩放。
- 默认跟随当前桌面，可开启“所有桌面显示”；使用 fullScreenAuxiliary。YAAGL/Wine 的实际全屏覆盖、Spaces 切换及输入穿透效果待用户实战验收，不能用单元测试代替。
- 保持关闭主窗口不退出进程的行为。M6 的菜单栏战斗汇总尚未实现。

验证：三模式离屏渲染、窗口不激活/不隐藏策略、穿透开关、跨桌面设置、模式及位置持久化、显示器断开后的位置修正；Swift 完整回归、格式检查、发布构建与签名检查。不操作或捕获用户屏幕。

使用：Cmd+Q 退出旧 App，打开 dist/HSR Damage Meter.app，点击“显示浮窗”；拖动背景定位，在菜单栏设置模式和穿透。若窗口不可点击，使用菜单栏“恢复浮窗操作”。
