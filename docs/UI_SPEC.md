# UI 规范

应用使用原生 SwiftUI，并在窗口和浮层管理处使用必要的 AppKit。

## 主面板

- 顶部显示全队总伤害、DPS 和 DPA；数字使用等宽字形。
- 伤害占比柱状图和角色明细表同时展示。召唤物伤害归入所属角色，柱色使用角色属性色。
- 明细表按伤害降序展示角色、伤害、占比和 DPS，不显示攻击次数或最高单次。
- 伤害类型使用中文显示，并与角色表的外框、首尾边界对齐。
- 敌人区域显示名称、立绘、当前/最大生命和已知实时状态；未知数据使用明确占位，不推测。
- 更新资料按钮位于重新连接按钮左侧；已是当前版本时给出简短状态，更新失败时保留现有资料。

主窗口默认尺寸为 1120×760，最小尺寸为 900×620。界面采用统一间距、圆角和 0.15–0.25 秒的克制动效，并遵守减少动态效果和辅助功能设置。

## 浮窗与菜单栏

浮窗支持 Minimal、Compact 和 Detailed 三种密度，默认 Compact。关闭鼠标穿透时可从窗口任意位置拖动；开启穿透后由主窗口或菜单栏提供可靠的关闭入口。

关闭主窗口不会退出应用。菜单栏使用 18pt 透明单色图标：空闲状态降低不透明度，战斗统计中提高亮度并显示绿色状态点。状态不能依赖颜色作为唯一提示。

## 数据状态

连接中、已连接、断线、空数据、统计不完整和演示数据必须可区分。DPS 的时间口径及 DPA 的行动值口径应与实际数据来源一致。未知技能、属性、敌人状态或版本兼容信息不得由 UI 猜测补全。

主要视图应提供稳定 fixture，用于单元测试、离屏渲染和无游戏环境开发。
